# 笔记本数量对应树形与首页比例修正

## 本轮要求与结果

- 一本笔记本严格对应一根主枝。分别为一、二、三本笔记本设计单主枝、双主枝和三主枝骨架；同一本上的细枝不增加笔记本入口。
- 首页和知识森林共用这些树形，知识点保留原始 ID 和笔记本归属。默认每本六个预览位，展开或定位更多知识点时保留已有点的位置。
- 首页三门课程继续同时显示。中心课程略偏左、偏上，两侧树的高度与间距错开；放大树、缩小课程名，并压缩页头和底部说明所占空间。
- 较矮的桌面窗口采用紧凑页头，优先给树留空间。手机布局未列入本轮设计范围。
- 原交接 `2026-10-22-sparse-canopy-triangle.md` 中“一本笔记本分布到三个主枝”的方案已由本轮的一对一方案替代。

## 实现与数据边界

- `naturalBranchGeometry.ts`：按 `crownSize` 选用单、双、三主枝的 authored recipe。
- `courseCanopyGeometry.ts`：每个默认笔记本生成一个主枝项，同步派生绘制路径、点击路径、叶柄和藤蔓坐标。
- `home-courses.css`：调大树与文字的比例，调整三角排列，增加桌面短窗口规则。
- 更改笔记本数量会切换树形；同一数量下 pin、搜索与目录刷新不会重排已有知识点。新建笔记本回归用例仍保护真实上传目标、原知识点归属、新笔记本生长标记与森林相机。
- 未更改已有课程、笔记或模型生成内容，未提交或推送分支。

## 验证

- 前端全量测试：33 项导航测试、179 项界面测试通过，总计 212 项。
- 生产构建通过；`git diff --check` 无空白错误。
- 只读审查：检查一、二、三主枝及 1/2/3/4/6 本目录的 30 组 pin/展开情形，知识点 ID、归属及已有位置均正确。
- 实际页面：1440×1000 树 SVG 高度约 414px；1265×720 短窗口约 318px，三棵树及其课程入口均在首屏内。
- 树形对照直接使用本机项目已有的 AI 生成目录切片渲染，不创建测试课程或伪造知识点。
