# 知识森林：错落树群与下方课程信息

## 本次修改

- 森林按稳定世界槽位分成三棵一组的树群：中间靠后，两侧前后不对称，并保留课程本身的自然变化。添加课程不会让已有树重新随机排列。
- 树与首页共用根株和树冠形象；保留一条主枝对应一本笔记本、叶子对应真实知识点。
- 每组课程名统一放到树根下方的同一基线，水平居中对齐各自树；首页选择和目录操作也跟随下方区域。
- 长课程名显示省略，保留完整可访问名称与悬浮标题，点击区域限制在自身课程槽内，避免误点相邻树。
- 三角树群的藤蔓使用真实笔记本锚点，绕开中间树和下方课程信息。跨组普通长藤蔓收敛，明确选中的远关系仍可定位。
- 初次进入框住前三棵课程树；保留缩放、拖动、适应全部课程、课程聚焦、枝干和叶子点击。
- 视图版本为 `grove-v1`：旧横排相机重新取景，新版视图继续恢复；旧快照不会阻止选中远关系及懒加载端点的自动定位。
