# 首页与知识森林外观美化

依据用户提供的[效果示意图](../软件工程文档/参考资料/效果示意图.png)，本轮仅调整前端外观。继续在 `feat/home-knowledge-forest` 开发，未提交或推送。

## 已调整

- 首页与知识森林限定使用暖纸色、深森林绿、鼠尾草绿与细边框；侧栏增加轻微材质层次，主按钮与次按钮区分清晰。
- 搜索框、浮层工具栏、圆形缩放按钮、首页课程选择器、森林设置面板与关系弹窗统一材质和交互状态。
- 标题采用本机宋体类衬线字体回退，与参考图的植物笔记风格接近；正文沿用原字体。
- 两个轻量静态 SVG 用于边缘枝叶与远处校园、地形装饰，不拦截输入；没有修改原树、叶、藤蔓素材、几何、点击目标或动画控制。
- 窄屏导航按钮不再挤到断字，森林页操作按钮改为横排换行，设置面板选择器有独立标签和完整宽度。

实现入口：`apps/web/src/features/forest/botanical-surfaces.css`，由 `main.tsx` 最后引入；装饰资源在 `apps/web/public/assets/forest/botanical-margin.svg` 和 `garden-distance.svg`。移除该新增样式引入即可撤销本轮外观覆盖。未改后端、API 调用或业务数据库。

- 前端现有测试：38 项 Node + 271 项 Vitest，共 309 项通过。
