## 已实现

每门课一本笔记本，每讲一个章节，按课件顺序组织独立小节。章节/整本阅读、上下小节、目录上下重排；各讲同名知识点共用概念而不合并正文；叶子和来源链接定位 Note ID。沿用小节编辑、修订、来源和建议机制，查询参数变化也保护草稿。

旧库自动升级前做检查点，单讲旧笔记保留原 ID 归入章节，多讲/无来源旧笔记保留历史整理。重解析保留小节 ID 和用户正文，变化形成建议；相似知识点先生成可读小节，确认/拒绝仅处理关系。上传、移除、恢复、重排通过目录版本防止旧顺序覆盖；本讲网络来源不混入其他讲。
