# 首页正在学课程

2026-10-22，当前分支 `feat/home-knowledge-forest`。保留同分支已有的树冠、背景、藤蔓及启动脚本改动。本次未提交或上传。

## 使用方式

- 森林工具区“首页正在学 n/3”打开课程选择列表，或使用每棵树树根左侧的小屋按钮。
- 放到首页同时将课程设为 `learning`；移出同时设为 `planned`。界面明确提示，笔记、资料、阅读进度全部保留。
- 首页只显示正在学的课程，最多三门。满额时先移出一门，系统不自动替换；完成课程仍从课程设置改为已完成。
- 首页没有正在学课程时，直接引导到 `/forest?home=manage`。返回首页和页面刷新均读取当前选择，不再使用访问时间或旧页面快照固定课程成员。

## 实现要点

复用森林课程 PATCH 的 revision。后端在同一 UPDATE 中检查活跃正在学课程数，防止两个旧读取同时抢占最后一个名额。删除课程不占名额；恢复时如首页已满，恢复的课程设为未开始，其他数据照常恢复。旧课程首次初始化也遵守三门上限。

森林页面的读取序号会在成功写入后失效，避免打开管理面板时的慢响应覆盖刚保存的状态。保存失败显示错误并重新读取，课程选择不乐观冒充成功。树根入口和对话框共用同一操作，支持键盘。
