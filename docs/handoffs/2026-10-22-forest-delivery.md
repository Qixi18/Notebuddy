# 知识森林与首页学习花园交付总结

分支：`feat/home-knowledge-forest`。本次汇总自 `9cded5a` 之后的修改，面向网页版交付。

## 已完成

1. **统一自然树形。** 首页和森林共享树冠、木纹主枝和新根株；为一、二、三本笔记本分别提供完整形态，保持一本笔记本对应一根主枝，知识叶仍对应真实知识点。修正主干接缝、错位和密集叶片点击遮挡。
2. **首页全部课程同屏。** 一至三门正在学课程自适应显示，取消分页；三棵树采用自然错落的三角布局。课程名、笔记本选择、继续阅读与添加入口统一放在树景下方，各自居中对齐树的位置。
3. **森林错落布局。** 使用稳定槽位形成前后高低不一的树群，新增课程保留已有树的位置；保留缩放、拖动、适应全部课程、地图与课程聚焦。课程名移至下方基线，限制长名称及点击区域，旧版相机自动迁移，新版相机继续恢复。
4. **优化并共用藤蔓。** 首页与森林共用渐变粗细、木质纹理、卷须和关系叶。每对课程最多四根显示藤蔓，分组保留全部真实关系；远距离关联可明确选择后定位。根据项目内置 AI 的实时关系和真实笔记本、知识点 ID 计算落点，前端负责密度、摆放与避让，不预设业务关联。
5. **保留完整交互。** 知识叶默认不常显名称，悬停或键盘聚焦可预览，激活打开准确笔记；主枝续读准确笔记本，根部提供资料与目录入口。关系叶可查看两端笔记和来源依据，选中的远关系同时容纳两个真实端点。
6. **管理首页正在学课程。** 森林新增首页课程选择面板和树根快捷入口，首页最多三门课程；服务端在写入时检查容量，覆盖并发争抢、旧课程初始化、删除释放名额与满额恢复场景。切换状态保留笔记、资料和阅读进度。
7. **界面与启动修复。** 森林增加柔和背景并修复左上角搜索、图例重叠。修复启动脚本在 Windows PowerShell 5 下的提示文本编码解析问题，语法检查通过。
