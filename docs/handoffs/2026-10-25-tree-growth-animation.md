# 知识树生长动画交接

分支：`feat/home-knowledge-forest`。本轮在上一轮首页／正文同步改动上继续实施，改动均留在本地，未提交、推送或合并。

## 已实现

- 首页和森林共享生长记录：新课程、笔记本、真实知识点和有效关联按实际 ID 识别，首次可见时播放，同一浏览器标签会话内跨页面及刷新不重复。
- 现有 SVG 素材通过原生遮罩沿路径显露；知识叶片围绕叶柄展开。空课程保持原有装饰树冠，装饰叶片不计作知识点。
- 原有创建跳转保持不变；等待目录就绪、弹窗关闭、页面可见及对象进入实际裁切区域后才领取动画。不会为动画切换首页课程、笔记本或相机。
- 同批父子内容衔接；已有藤蔓新增关系只展开新关系叶片。超出树木、叶片和藤茎预算的内容正常静态显示。
- 点击／聚焦时先完成动画再走原有操作；页面隐藏、卸载、减少动态效果变化、原生 API 失败均清理临时效果并显示完整内容。
- 资料／正文恢复及绑定已有笔记本建立基线，避免误当新建；失败保存、冲突与未完成的上传不生成虚假知识叶片。

代码入口：`apps/web/src/features/tree/growth/` 为状态、裁切可见性与绘制控制；共享树冠及藤蔓组件只增加绘制描述。创建、保存和后台读取的成功分支登记真实结果。无新运行时依赖、后端接口或数据库迁移。

内部停用开关：前端启动／构建环境设置 `VITE_TREE_GROWTH_ENABLED=false` 后重新启动／构建，内容静态显示。该开关不改变数据和导航。

## 验证证据

- 最终前端：`npm test -- --maxWorkers=2`，38 项 Node 测试及 270 项 Vitest（53 文件）通过，共 308 项。新增生长回归 19 项；`npm run build` 通过，仍有既有的大分包提示。
- 独立审查的两项问题已修复并经失败→通过回归：屏幕外藤蔓不能消耗事件；第三条新藤茎不开始第二波。另补测平移后进入视口、存储配额、资料恢复和动态减少动画。
- 修改前保存空树、单／双／三主枝和森林截图。首页几何路径、叶片坐标和命中范围逐项相同；空树和双主枝最初前后截图即逐像素一致。重新用原绘制组件对照并对齐稳定加载／相机后，三主枝和森林也逐像素一致。
- 原绘制对照副本仅存在本地 QA 目录；保留上一轮首页选择恢复语义，不改写产品源文件。首次未稳定加载的截图不作为最终等价证据。单主枝的稳定原版／新版对照也为零差异：`growth-controlled-base-home.png` 与 `growth-controlled-after-home.png`。
- 真实浏览器观察到枝干和叶片播放中的临时遮罩、结束后的清理；隔离 API 数据中创建课程成功，并保留跳转到课程详情的流程。新课程默认未开始时不擅自放到首页。
- Edge 中确认实际视口 390×844、1024×768、1440×900，三个样例均无新增横向溢出。窄屏仍保留本来的三列展示，不属于本轮布局优化。
- 本机同一批量更新样例，原版与动画版均无 ≥50ms 长任务；1900ms 后活动效果与临时遮罩均为零。大规模真实课件及不同设备仍需产品级性能验收。
