## 功能变化

- 知识树：放慢新课程、笔记本和知识点的生长节奏，枝梢增加暖金色光点和光尾，叶片展开时出现柔光与粒子。新增笔记本实测森林约 3.9 秒、首页约 5.5 秒（含余光）。
- 首页风动：可见叶片及细枝错峰摆动一轮后归位，树根、主干、文字和点击热区固定。生长优先，阅读时无循环摇摆。
- 新藤蔓：两端同时出光，藤蔓茎紧跟光前沿向中间生长。双端遮罩和光共用绝对时间起点、2400 ms 时长及线性进度；中间尚未到达的部分保持隐藏，最终在中点接通并融合、扩散、淡出。
- 叶柄、叶片和卷须按连接点的真实弧长位置等待光前沿到达后生长；已有藤蔓追加关系时只展开新增部分。悬停或键盘聚焦可重播光效。
- 支持减少动态效果、页面隐藏、弹窗、布局改变、交互中断及卸载清理。关系叶折叠时，可见藤蔓仍播放生长；其他屏幕外事件保持待播。

## 文件与依赖

`apps/web/src/features/tree/growth/` 管理生长时序、遮罩及光效；`motion/` 管理一次性风动、汇聚光效和资源清理。`HomeCourseTree`、`CourseCanopy`、`NaturalBranchWood` 和 `KnowledgeLeaves` 将叶片绘制与热区分离；`TreeVines`、`VineLayer` 提供路径方向、连接点与播放协调。

依赖方向保持首页/森林 → 树及藤蔓组件 → 视觉绘制助手。业务逻辑/API/公共数据结构变化：无。数据库迁移：无。无新增依赖；未修改 Notebook 正文、后端、关系存储、生长事件账本或既有几何路由语义。
