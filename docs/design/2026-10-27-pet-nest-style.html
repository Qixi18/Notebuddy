窝怎么不长在另一个画风里

角色是插画层：粗描边、外侧白贴纸边、两阶光影、手绘曲线。现在的窝是UI 层：1px 细线、正椭圆、平涂、没有描边。两个层本身都没错，混在一起才是割裂的来源。

现在的窝 · 代码线

UI LAYER
  • 1–2px 冷灰线，没有闭合外轮廓，边缘是填充边界
  • 正椭圆 + 直排线，几何感强，和她的曲线不是一支笔
  • 平涂，没有暗部，放在她旁边像一张贴纸底下的色块

同画风的窝 · 角色线

推荐
  • 3.5px 暖黑描边 + 14px 冷白贴纸边，和她的轮廓是同一支笔
  • 叶片环绕，不是一圈直排线或轮胎花纹
  • 两阶冷绿 + 奶油垫，暗部偏冷，不跳暖棕
  • 白花 / 菱形宝石，从她身上取的元素，不是另一种世界观

三条解法，按优先级

  1. 让窝回到插画层（最稳）。和角色同一支笔、同一套描边和光影，画成一张独立的 PNG。代码只负责 back / front 两层定位，不再用 CSS/SVG 画窝。
  2. 如果必须代码画。至少补齐四件事：深色闭合外轮廓、外侧冷白贴纸边、圆头粗笔触、两阶冷色阴影。现在这版四个都缺，所以看着像 UI 控件。
  3. 不要跨材质。棕色藤篮、木纹、棉麻是另一套世界观；她的世界里是白花、菱形宝石、浅蓝羽纱，窝的材质要从这里长出来。
判断标准很简单：把窝和角色放进同一张图，眯眼看——如果窝先变成一块“干净的矢量色块”，它就是 UI 层，还没进她的世界。

睡眠形态要改几何

  • 深碗只能站。她一趴下，前沿会挡掉半张脸和身体，只剩一撮头发。
  • 改成后高前低的浅口床：前沿低于下巴，后沿略高过头顶，垫子要平、要宽。
  • 拆成 nest-back / nest-front 两层 PNG。站着时前沿压住脚踝；趴下时前沿可以降下去或被身体盖住。
  • 毯子单独一层。睡觉时她可以拉过来，不睡时搭在后沿。
