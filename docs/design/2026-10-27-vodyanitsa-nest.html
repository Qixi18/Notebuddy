沃雅妮莎的窝

先把人查清楚，再决定窝长什么样。三个方案都按 240px 真实栏宽、粗描边 + 冷白贴纸边画，每张卡片可切「站着 / 趴睡 / 空窝」。

一、她是谁

  • 水妖，不是人类：本名 Vodyanitsa，至冬水妖一族；水元素神之眼，命之座「金鳍座」，称号「幽歌萦渊」。
  • 科洛列夫茨基剧团首席女高音：族人散去之后，她仍留在剧院登台，是少数没离开舞台的歌者。
  • 外形：墨绿长卷发、蓝眼、右眼被刘海遮住、鳍状耳、肩腿有青蓝鳞纹；白色十字花 + 珍珠头链，白色立领下挂着圆形话筒。
  • 水妖形态：双腿变青绿水晶鱼尾，尾端浮着金属圆环，两胯装饰白色薄纱。
  • 性格：心思细腻，怕自己「不被需要」。每次动了回家的念头，就找十个至冬人问是否爱听她唱——只要有一个需要，她就留下。
  • 场景：剧院、后台、演出准备室。台词里念着「帕拉斯科娃」「谢尼娅，你的曲子」——她的世界是排练、乐谱、开演前的独处。

二、故事能拿什么，不能拿什么

她的设定不能做应该做
水妖 / 鱼尾 / 鳞纹 木架、藤编、棉麻、暖棕陶土——那是林间小屋，不是水生生物 贝壳、珍珠母内衬、水面、鳞片状叠压；圆润、湿润、半透明
首席女高音 / 剧院 红丝绒大幕、金色雕花、满墙乐谱——太重，240px 下只剩噪点 香槟金滚边、丝绒的哑光质感；一处乐谱或话筒的暗示，够了
至冬 / 寒地 暖黄灯光、炉火、夕照——温度错了 冷白、霜、冰晶、冷蓝阴影；光是「舞台脚灯 + 雪光」
她的配色 暖奶油、原木、砖红，以及——整片墨绿 珍珠白 + 雾蓝打底，墨绿只做小面积，金只做点睛
最要紧的一条：窝不能用墨绿。她体量最大的是那头墨绿卷发（原图最深处 #436465）。上一版我画的深绿碗，她一坐进去，头发和窝底就糊成一块，人反而没了。把窝做成珍珠白 / 雾蓝，她的深发才跳得出来——这是从她的配色反推的，不是审美偏好。

三、三套方案

推荐

A · 珍珠贝软榻

水妖睡贝壳，设定里最省力也最准的一张牌。贝壳天生后高前低，前瓣抬起来就是被子。

♪ ♪
  • 前瓣抬 12° 就是被子，不用另画毯子
  • 头发溢出壳沿，是「真的被装进去」的唯一信号
  • 贝壳不能是墨绿，会和头发糊成一块
剧院向

B · 后台丝绒榻

把「首席女高音」直接演出来：墨绿丝绒、香槟金滚边、一张摊开的乐谱。

  • 剧院身份最直白，一眼知道她是谁
  • 丝绒墨绿和她的头发同色，人和窝容易黏在一起
  • 靠背太挺，像家具不像窝
轻量向

C · 冰湖水面

不给她做一个窝，给她一汪水：水妖本来就该待在水里，睡在涟漪中间。

  • 画风最省：只要椭圆 + 两道涟漪，天然是软的
  • 睡在水面上、头发散开，是这套里最好看的一帧
  • 「窝」的容器感最弱，更像一个站位
选 A，但把 B 的金线拿过来用。A 的贝壳给出容器和睡眠几何，B 的香槟金滚边给出「剧院」的身份线索——沿贝壳前沿加那道金线，一克就够。C 的涟漪可以当 A 里的水面反光，叠在内衬下方。

五、睡眠这一帧怎么定

项做法
姿态蜷在贝壳里，侧卧偏趴，膝盖收向胸口；头枕壳沿内侧，脸朝画面右下（观众看得见闭眼的脸）
头发铺满壳内、溢出前沿 10–16px。头发是她最大的体量，不铺开就看不出「装进去了」
被子前瓣抬 12°，遮到腰。不用另画毯子——贝壳本身就是被子，这是这个方案最值钱的地方
呼吸身体起伏 2px，叠加前瓣 1.5px，同步 2.4s；头发滞后 2 帧
提示符号冒 ♪ 不冒 Z。她连打盹都在唱歌，这一笔比任何表情都更像她
触发60s 无输入且无任务；点一下或有请求立刻醒——先抬头，再回 idle，不要直接跳
时长进入 8 帧 / 循环 32 帧（≈2.7s）/ 醒来 10 帧
