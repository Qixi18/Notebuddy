# 桌宠动作与彩蛋设计（沃雅妮莎）

> 2026-10-28 · 记录当前已接入的动作、已实现/待拍的彩蛋，以及素材与接入约定。
> 目的：动作设计散落在对话里容易忘，这里做唯一口径。

## 1. 素材与资产约定

- 源：`D:\王金赛\matte-studio\jobs\<中文动作名>\{frames,alpha}`，720×960、24fps、透明分离帧。
- 产物：`apps/web/public/assets/pet/<动作 id>.webp`（408×544 画布、12fps、透明、`-loop 0`）+ `manifest.json` + `preview.html`。
- 生成：`python scripts/build_pet_actions.py <id...> --job-root "D:/王金赛/matte-studio/jobs" --canvas 408x544 --quality 70`
- **所有动作必须同机位同画布**，切动作时人物才不会跳大小（实测各动作首帧包围盒都在 x 75–336 / y 140–492）。
- 长动作拆「正片 + 往复段」时，**往复段的 range 末帧要和正片末帧对齐**，否则切换会跳（讲解正片末帧=源 238，所以往复段取 214–240；接缝 PSNR 34.5dB）。

## 2. 主线动作（已接入，`usePetAction`）

| 触发 | 动作 | 备注 |
|---|---|---|
| 无事 | `idle` | 5.83s 往复循环 |
| 思考中、未吐字 | `thinking-intro` → `thinking-loop` | 先 0→75 正放，再 75↔22 往复 |
| 正文开始吐字 | `explaining` | 不等整段生成完 |
| 讲解 10s 播完还在吐字 | `explaining-loop` | 源 214–240 往复，2s |
| 吐字结束 | 播完当前一轮 → `idle` | 不半截掐断 |
| 回答失败 | `error` | 5s 一次，回待机 |
| 悬停 ≥3s | `greet` | 只在待机时 |
| 没吐字就结束（中断/空回答） | 直接 `idle` | 不误播 10s 讲解 |

当前资产：7 个动作 / 约 9.0MB（`idle` 1.5M、`thinking-intro` 836K、`thinking-loop` 1.2M、`explaining` 2.6M、`explaining-loop` 528K、`error` 1.3M、`greet` 1.3M）。

## 3. A 档彩蛋（已实现，零新增素材）

规则：**每个彩蛋每页面会话只放一次**；触发时正在思考/输出则挂起，等这一轮结束再放，避免打断动作。

| 彩蛋 | 触发 | 动作 | 台词 |
|---|---|---|---|
| 别把我当铃铛 | 3s 内连点 8 下 | `error` | 我唱的是咏叹调，不是门铃。 |
| 你刚才问过了 | 10 分钟内重问同一句（重试按钮不算） | `greet` | ……上一句，我唱得不够清楚吗？ |
| 夜场 | 00:00–05:00 打开答疑页（2.5s 后） | `greet` | 这个点的剧场，回声最好听。 |
| 停笔 | 输入框有草稿且 30s 没动 | `thinking-intro` | 我在等你的下一句 ♪ |
| 失焦归来 | 离开 ≥60s 再回来 | `greet` | 你回来了。刚才那段，我唱到第二幕了。 |

实现：`petEggs.ts`（文案/动作映射/节流/提问信号总线）+ `usePetEasterEggs.ts`（五个触发器）+ `usePetAction` 的 `command` 插播参数。

## 4. B 档彩蛋（需补拍动作）

拍摄要求与主线一致：720×960、24fps、透明、同机位、单动作 3–5s、首尾尽量回到中性姿势（便于接 `idle`）。

| 彩蛋 | 触发 | 动作要点 | 建议帧段 |
|---|---|---|---|
| 谢幕 | 连续答对 3 题（考考我/测验） | 提裙、颔首、抬手；她习惯谢幕，不习惯被夸 | 0–120 |
| 打盹被抓包 | 闲置 10min → `sleep`；鼠标靠近惊醒 | 蜷在窝里；惊醒时圆环一颤，然后装作没睡 | 0–96 + 惊醒 20 帧 |
| 躲进圆环 | 连续 2 次回答失败 | 背对你、缩进圆环 2s，再自己转回来 | 0–72 |
| 唱歌 | 问题含“唱/歌/咏叹调/歌剧” | 闭眼、抬手、♪ 飘出 | 0–120 |
| 半张脸 | 贴边隐藏状态持续 3s | 从边缘探出半个头偷看再缩回 | 0–48 |

> 这些都需要先在 matte-studio 里出一版素材，再按第 1 节的命令构建；动作 id 定好后加进 `petActions.ts` 与 `manifest`。

## 5. C 档（跨页面 / 长期记忆，成本最高）

- **知识森林彩蛋**：在森林页她坐在树枝上，回答疑页才回窝。
- **第七天**：localStorage 记首次使用日期，第 7 天首次打开说「第七天了，你每次都坐在同一个位置。」
- **草稿回响**：记住昨天没问完的半句，主动问「昨天那句……还问吗？」

## 6. 克制原则

1. 彩蛋总数控制在 5 个以内，多了就是噪声，不再是彩蛋。
2. 每个彩蛋有频率上限（当前：每会话一次）。
3. 台词挂人设（剧团女高音、怕「不被需要」），但**不许自贬或卖惨**——委屈可以有，可怜不要。
4. 彩蛋只借用已有动作，宁可复用也不要为一句台词加一整套素材。
