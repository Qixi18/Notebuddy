# 知识森林树形与藤蔓实施计划

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 统一首页和森林树形，用最多四根分组藤蔓连接每对课程，具体关系以藤蔓叶表达。

**Tech Stack:** React 19、TypeScript、SVG、现有 d3-zoom、Vitest。
