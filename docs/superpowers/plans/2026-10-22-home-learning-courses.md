# 首页正在学课程实施计划

> 使用 executing-plans 在当前任务逐项实施；保留当前分支及已有未提交改动，不提交或上传。

**目标：** 在知识森林明确选择放到首页的课程，放入即设为正在学，首页最多三棵树。

**方案：** 复用 `learning_state=learning` 作为唯一状态来源；首页不再由最近访问或旧页面快照决定成员。移出首页恢复 `planned`，界面明确说明学习状态变化，笔记、资料和阅读进度不变。已有“已完成”仍通过课程设置选择。满额不自动替换其他课程。桌面网页优先。

**接口：** 复用课程状态 PATCH 和乐观版本号。在同一 UPDATE 条件里检查活跃正在学课程数量，防止并发突破三门；删除课程不占名额，满额恢复的课程先回到未开始。旧课程初始化也遵守名额限制。

**入口：** 树根旁的小屋按钮；工具区“首页正在学 n/3”打开完整课程选择列表，低缩放或远处的课程也能管理。首页空位引导用户去森林选择课程。
